# ShowOps-Web agent boundary

This public repository contains the publishable ShowOps presentation layer, generic client behaviour, public assets, fixtures, and intentionally public contracts only.

Do not add customer handoffs, personal or staff records, commercially sensitive plans, secrets, privileged endpoints, private operational data, tenancy or identity authority, audit truth, conflict-resolution policy, or authoritative backend business rules. Those belong in the private `langzonedev/ShowOps` repository.

Prototype data must be clearly fictional. Public prototypes must truthfully label local-only storage, offline behaviour, authentication, synchronisation, recovery, and production readiness.
